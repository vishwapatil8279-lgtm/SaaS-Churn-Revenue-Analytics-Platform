# SaaS Churn & Revenue Analytics Platform

## Project Overview

This project analyzes SaaS customer revenue, usage, support activity, churn and retention.

The project covers the complete analytics workflow:

1. Data audit and cleaning
2. NumPy analysis and normalization
3. Pandas wrangling and exploratory analysis
4. Statistical analysis
5. Cohort and retention analysis
6. Visualization
7. Customer segmentation using K-Means
8. Churn risk scoring
9. SQL business analysis
10. Excel reporting
11. Power BI dashboard
12. Executive summary

## Business Objective

The objective is to identify:

- Revenue performance
- Customer churn patterns
- Retention behavior
- Customer segments
- Usage and support signals associated with churn
- Customers with elevated churn risk
- Revenue exposed to churn risk
